# Матрица совместимости

Используй эту таблицу как контрольный список, а не как доказательство наличия конкретного API DeepSeek Harness.

| Слой исходного скила | Что обычно сохраняется | Что проверять и адаптировать |
|---|---|---|
| Название и описание | Назначение и границы активации | Синтаксис frontmatter, правила обнаружения скила |
| Основной workflow | Порядок принятия решений и критерии готовности | Доступные инструменты, формат сообщений, лимиты контекста |
| Инструменты | Семантическая роль операции | Точные имена, аргументы, подтверждения и результат вызова |
| Файлы references | Доменные правила и схемы | Относительные пути, способ чтения файлов, актуальность ссылок |
| scripts | Детерминированная автоматизация | Команда запуска, права, интерпретатор, код возврата |
| agents/openai.yaml | Только UI-метаданные для совместимой среды | Не переносить автоматически в Harness без подтверждённого контракта |
| Политики безопасности | Запрет секретов и контроль побочных эффектов | Механизм approval/confirmation целевой среды |

## Минимальная проверка перед выдачей

- frontmatter разбирается выбранным валидатором;
- все локальные ссылки разрешаются относительно каталога скила;
- отсутствуют `[TODO]`, фиктивные токены и необъяснимые заглушки;
- каждая внешняя мутация имеет понятное условие разрешения;
- отчёт отдельно отмечает факты, проверенные по документации Harness, и предположения.
