# Веб-парсинг

- Перед реализацией определи источник, допустимый объем, частоту запросов, формат результата и правила хранения.
- Для статичного HTML используй HTTP-клиент и HTML-парсер; браузерную автоматизацию включай только для реально динамического контента.
- Настрой connect/read timeout, ограничение скорости, retry с экспоненциальной задержкой и понятную остановку после серии ошибок.
- Нормализуй URL, кодировки, даты и идентификаторы; удаляй дубликаты по стабильному ключу.
- Сохраняй checkpoint, чтобы перезапуск не начинал работу с нуля. Логи не должны содержать cookies, токены или персональные данные.
- Уважай robots.txt, условия использования и запросы на удаление данных; не обходи защитные механизмы.
