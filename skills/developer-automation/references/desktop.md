# macOS и Windows

## macOS

- Для Swift используй SwiftPM, `async/await`, `guard` и типизированные ошибки.
- Проверяй разрешения sandbox, Accessibility, Files and Folders и Keychain до обращения к защищенным ресурсам.
- Нативную автоматизацию делай через официальные API; AppleScript оборачивай в `try/on error` и сообщай пользователю, что именно не удалось.

## Windows

- Учитывай Unicode-пути, разделители, права доступа и различия PowerShell 5.1/7.
- Для секретов предпочитай Credential Manager или другой защищенный механизм вместо файлов в репозитории.
- При упаковке фиксируй архитектуру, версию runtime и способ обновления; проверяй запуск на чистой машине.

## Общие требования

- Отделяй платформенный код от общей бизнес-логики.
- Обрабатывай SIGINT/закрытие окна и освобождай временные файлы, процессы и сетевые ресурсы.
- Документируй команды сборки, минимальную версию ОС и ручные разрешения, которые нужно выдать.
