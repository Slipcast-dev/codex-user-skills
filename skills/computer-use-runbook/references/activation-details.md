# Полные условия применения

Write the step-by-step runbook a computer-use or browser agent follows to finish a real online task, such as cancelling a subscription or changing an energy supplier: what to look for on screen, one action per step, how to know it worked, and where to stop for a human. Use when asked to write instructions for a browser agent, make my agent cancel or change something online, or check whether a task is safe to hand to an agent. Produces the runbook, the stop points and the final verification.
