# Data-source fallback contract

1. Discover available tools without assuming an MCP tool name. Use connected Ahrefs where authorized and available.
2. If absent, inspect user-provided exports. Record export time, target, filters, units and known coverage. Never equate metrics from different providers without reconciling definitions.
3. Use authorized Search Console/analytics data and public-page inspection for the dimensions they actually support. A public crawl cannot substitute for backlink-index coverage or private conversion data.
4. Deliver verified dimensions now. For each unavailable dimension list the missing input, affected conclusion and exact export needed to finish. Do not fabricate numeric substitutes or claim a full pass.

For a quick audit prioritize the requested pages and symptoms. For due diligence retain the full dimension checklist. External writes, paid crawls and scheduled monitoring require the applicable task authorization; proposing a cadence does not create an automation.
