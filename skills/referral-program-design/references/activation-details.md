# Полные условия применения

Design a referral or viral-loop program that actually drives growth. Use when asked to design a referral or refer-a-friend program, build a viral/invite loop, set referral incentives, turn happy users into a growth channel, or improve word-of-mouth growth. Produces a referral design — the loop mechanics, incentive structure (who gets what, when), the viral-math estimate (k-factor/cycle time), the unit-economics check, fraud guardrails, placement & messaging, and success metrics.
