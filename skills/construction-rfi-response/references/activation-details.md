# Полные условия применения

Answer a construction request for information so the site can act on it — a direct answer, the drawing or specification reference that supports it, and an explicit statement of whether it changes cost or programme. Use when asked to respond to an RFI, answer a contractor query, or handle a request for information on site, or when RFIs keep coming back for clarification. Produces the answer with its reference, the cost and time implication stated, the instruction status, the distribution list, and the register entry.
