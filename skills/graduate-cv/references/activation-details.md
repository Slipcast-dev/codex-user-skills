# Полные условия применения

Write a first CV for a student or recent graduate with little work experience, using coursework, projects, part-time jobs, societies and volunteering as real evidence. Use when asked to write my first CV, graduate CV, internship resume, I have no experience what do I put, or my CV for campus recruitment or a graduate scheme. Produces a one-page CV with education first, evidence-based project and activity bullets, a skills section tied to proof, and a list of quick additions that would strengthen it before deadlines.
