# Полные условия применения

Prepare, before you need it, the runbook for stopping a proactive agent that is misbehaving: how to pause it in seconds, which connections to revoke in what order, how to check what it did, who to tell, and how to restart safely. Use when asked what to do if my agent goes wrong, make a kill switch plan for Duet, how do I stop my AI agent, my agent sent something it should not have, or prepare an emergency plan for an always-on agent. Produces a one-page runbook with the pause step, the revoke order per connected app, the activity check, message templates for anyone affected, and the restart checklist.
