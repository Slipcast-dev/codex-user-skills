# Полные условия применения

The gate before an agent sends anything on your behalf: one card showing recipient, sending account, subject, attachments, and the single sentence that commits you to something, so approving the wording is never mistaken for approving the send. Use when asked to check before sending, show me exactly what is about to go out, set up a send approval gate, or review this outgoing email or message an agent drafted. Produces the approval card, the commitment sentence quoted, the risk flags, and an explicit approve-the-send question separate from the draft.
