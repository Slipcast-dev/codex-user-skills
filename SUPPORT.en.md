# Support and questions

Start with [the README](README.en.md), [the catalog](CATALOG.en.md), and the relevant skill's `SKILL.md`. Check its external dependencies and license.

## Catalog or installation problems

Open an [issue](https://github.com/Slipcast-dev/codex-user-skills/issues/new/choose) and include:

- the skill name and a link to its folder;
- the release or commit you are using;
- operating system and installation method;
- expected and actual results;
- minimal reproduction steps without personal data or secrets.

Use the appropriate template to propose a new skill or category. See [CONTRIBUTING.en.md](CONTRIBUTING.en.md) for contribution instructions. Russian and English documentation and issue templates are available; skill files retain their source languages.

## Problems with other projects

Report problems with Codex itself, an external API, an MCP server, or a third-party application to the relevant project or support service. This collection does not provide official OpenAI support. Codex documentation: [skills](https://developers.openai.com/codex/skills).

Report security issues according to [SECURITY.en.md](SECURITY.en.md), rather than posting technical details in an open issue. Project support is provided as time permits, without a guaranteed response time.
