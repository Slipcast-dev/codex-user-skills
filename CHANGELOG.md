# История изменений

## 1.1.0 — 2026-11-03

- Документация и навигация по каталогу на русском и английском языках.
- Английские версии страниц категорий, сведений о лицензиях и происхождении, документов сообщества и переключатели языка.
- Переводы русских описаний для английского каталога; исходные инструкции и ресурсы навыков сохранены на своих языках.
- Двуязычные шаблоны issue и pull request, бейдж языков RU/EN.

## 1.0.0 — 2026-11-03

- Первая публичная коллекция из 1809 пользовательских навыков для OpenAI Codex.
- Каталог по 22 тематическим категориям с описанием каждого навыка.
- Исходные лицензии и происхождение, инструкции установки и документы сообщества.
- Проверки каталога в GitHub Actions и архив релиза со счётчиком скачиваний.
